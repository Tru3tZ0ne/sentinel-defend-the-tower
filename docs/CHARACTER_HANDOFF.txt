Character architecture:
- src/world/character-visuals.js loads and validates local GLBs, normalizes standing
  height and floor offset, clones skeletons, shares render resources and crossfades
  idle/walk/work actions. There is no Adobe dependency at runtime.
- src/world/people.js continues to own navigation and behavior. Async replacement
  preserves each existing navigation group, personId, position, route and FX
  references. Animation offsets must never modify navigation coordinates.
- src/main.js starts without waiting for assets and applies them to the current
  people instance without rebuilding the mission. Partial downloads use the
  available character; complete failure leaves procedural fallback figures.
- Shared character meshes are excluded from stage resource disposal on restart.
  Per-instance mixers and skeleton bone textures are disposed separately.
- tools/convert-mixamo.py rebuilds game-ready GLBs from authorized local FBX
  downloads using bpy 4.2.23 and Pillow. Raw source downloads stay outside Git.
- npm run test:characters covers delayed assets, preserved setup purchases and
  entity identity, real animation poses, feet grounding, navigation drift,
  cross-floor movement, zero-delta pause, restart resource sharing, EN/ZH and
  partial/complete asset failure. It is also included in npm test.
