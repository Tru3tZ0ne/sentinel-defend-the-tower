# Equipment card artwork

The nine equipment WebP images are original renders of the native Three.js meshes in `src/stand/sangfor-art.js`. They are generated by `npm run render:stand-art`; the browser-side rendering helper is `tools/render-stand-art-page.js`. Version 2 references actual product-family features documented below.

Corporate and product decals use the existing official images credited in `assets/brand/ASSETS.md`. Equipment is original arcade concept art, not a real appliance specification. No downloaded third-party models, paid assets, external generation service or new runtime dependency is used.

The modular Sentinel mech in `src/stand/mech-art.js` is original procedural
geometry using the same native mesh-building helpers and existing official
decals. Its armor, weapons and product mounts are fictional gameplay concepts.
It adds no external model files or new raster assets. See
`docs/STAND_CHAIN_MECH.md` for the current release and validation record.
The chain-mech refinement adds rounded armor, metal joints and piston details
with the same procedural helpers. It introduces no new external art assets.
The active Agent Builder release reuses the existing cached wrist controller
only during workflow execution. Its step trace is native HTML/CSS; no new
downloaded or generated art is introduced. See `docs/STAND_AGENT_WORKFLOW.md`.
The matte-arena release redesigns the native mounted pods, visor, shield and
arena, and re-renders the same nine WebP previews with the painted/composite
palette. The 1024px arena texture is generated once in canvas. All official
marks and reference photographs remain unchanged; no external models, image
generation service or new runtime asset dependency is introduced. See
`docs/STAND_MATTE_ARENA.md` for the current design and validation record.
